정면·후면 영상을 한 화면으로 합치고, 필요한 구간만 잘라 안전신문고 첨부 한도 130MB에 맞춰 저장해요. 휴대폰 앱과 윈도우 PC 프로그램 모두 무료예요. 광고도 회원가입도 없어요.

FEATURES

신고에 필요한 편집만, 쉽게

블랙박스 영상을 안전신문고에 올리기까지 필요한 작업을 한 번에 끝낼 수 있어요. 휴대폰 앱과 PC 프로그램의 기능은 같아요.

정면·후면을 한 영상으로

한 파일에 함께 녹화된 여러 영상 트랙을 동시에 재생해요. 위아래나 좌우로 붙여 하나의 영상으로 저장하니 상황이 한눈에 보여요. 4채널 블랙박스는 2×2로 모아 볼 수 있어요.

타임바로 자르기

타임바 양 끝을 끌어 필요한 구간만 남겨요. 파일 경계를 넘어도 한 번에 잘려요.

여러 파일 이어 붙이기

짧게 끊겨 녹화된 파일을 고른 순서대로 하나의 타임바로 이어요. 꾹 눌러 끌면 순서를 바꿀 수 있어요.

130MB 실시간 용량 표시

편집하는 동안 예상 용량을 안전신문고 첨부 한도와 비교해 보여줘요. 원본·높음·보통·낮음 화질로 용량을 조절할 수 있어요.

소리 포함·제거

차 안 대화나 음악이 들어갔다면 저장할 때 소리를 빼고 영상만 남길 수 있어요.

설치 방법

신고컷은 앱 마켓 밖에서 배포하는 프로그램이라, 처음 한 번은 보안 경고를 넘겨야 해요. 기기마다 메뉴 이름이 조금 다를 수 있어요.

안드로이드

APK 내려받기

휴대폰 브라우저(크롬, 삼성 인터넷 등)에서 APK 다운로드 버튼을 눌러요. ‘유해할 수 있는 파일’ 안내가 나오면 그래도 다운로드를 눌러요.

파일 열기

다운로드 완료 알림이나 내 파일 › 다운로드 폴더에서 singocut-1.7.0.apk를 눌러요.

이 출처 허용

‘보안을 위해 이 출처의 앱을 설치할 수 없어요’가 나오면 설정을 눌러 이 출처 허용(또는 ‘알 수 없는 앱 설치’)을 켜고 뒤로 돌아와요.

설치하고 실행

설치를 눌러요. Play 프로텍트 경고가 뜨면 세부정보 더보기 › 그래도 설치를 눌러요. 설치가 끝나면 열기로 바로 시작해요.

1.5.x 이하를 쓰고 계셨다면 1.6.0부터 앱 내부 식별자가 바뀌어, 그냥 설치하면 신고컷이 두 개 생겨요. 휴대폰에서 기존 신고컷을 먼저 삭제한 뒤 새로 설치해 주세요. 저장해 둔 영상(갤러리 Movies/신고컷)은 지워지지 않아요.

설치가 끝난 뒤에는 보안을 위해 브라우저의 ‘이 출처 허용’을 다시 꺼 두어도 앱은 그대로 쓸 수 있어요. 새 버전이 나오면 앱에서 알려 드리고, 같은 방법으로 덮어 설치하면 돼요.

윈도우 설치판

설치 파일 내려받기

보안 경고 넘기기

파일을 실행했을 때 파란 ‘Windows의 PC 보호’ 창이 뜨면 추가 정보를 누른 뒤 실행을 눌러요.

설치하고 실행

안내에 따라 설치를 마치면 시작 메뉴와 바탕화면의 신고컷으로 실행해요. 지울 때는 설정 › 앱에서 제거하면 돼요.

윈도우 포터블판

파일 내려받기

포터블 다운로드로 singocut-portable-1.0.2.exe를 받아 원하는 폴더나 USB에 넣어 두세요.

더블클릭으로 실행

설치 과정 없이 바로 열려요. 처음 한 번은 준비하느라 10초쯤 걸리고 다음부터는 바로 열려요. 보안 경고가 뜨면 추가 정보 › 실행을 눌러요.

업데이트는 새 파일로

새 버전이 나오면 프로그램이 알려 드려요. 이 사이트에서 새 포터블 파일을 받아 바꿔 쓰면 돼요.

FAQ

자주 묻는 질문

정말 무료인가요?

네, 안드로이드 앱과 윈도우 프로그램 모두 완전 무료예요. 광고나 회원가입, 결제가 없어요.

영상이 서버로 올라가나요?

아니요. 편집과 저장은 모두 휴대폰이나 PC 안에서 이루어지고, 영상은 어디에도 업로드되지 않아요. 인터넷은 새 버전이 있는지 확인할 때만 써요.

윈도우 설치판과 포터블판은 뭐가 다른가요?

기능은 같아요. 설치판은 시작 메뉴에 등록되고 프로그램 안에서 바로 업데이트돼요. 포터블판은 설치 없이 파일 하나로 실행되고, 업데이트할 때 새 파일을 받아 바꿔 쓰면 돼요.

안전신문고에는 어떻게 올리나요?

휴대폰에서는 저장이 끝난 뒤 공유하기로 안전신문고 앱에 바로 첨부하거나, 안전신문고 앱에서 갤러리의 신고컷 폴더 영상을 고르면 돼요. PC에서는 안전신문고 웹사이트에서 저장한 파일을 첨부하면 돼요.

130MB를 넘으면 어떻게 하나요?

편집 화면의 용량 표시를 보면서 구간을 더 짧게 자르거나 화질을 ‘보통’·‘낮음’으로 낮추면 용량이 줄어요. ‘130MB에 맞춰 자동 조절’을 켜도 돼요.

갤러리에 블랙박스 영상이 안 보여요.

AVI, TS 같은 형식은 갤러리에 안 보일 수 있어요. 첫 화면의 ‘갤러리에 안 보이면 파일에서 찾기’를 눌러 파일 앱에서 직접 골라 주세요.

신고컷이 두 개 보여요.

1.5.x 이하 버전과 1.6.0 이후 버전은 앱 식별자가 달라서 따로 설치돼요. 예전 신고컷을 삭제해 주세요. 이미 저장한 영상은 갤러리에 그대로 남아 있어요.

아이폰이나 맥에서도 쓸 수 있나요?

지금은 안드로이드(Android 10 이상)와 윈도우만 지원해요.
